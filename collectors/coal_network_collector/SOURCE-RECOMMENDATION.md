# 煤炭—火电数据源建议

| 来源 | 建议采集内容 | 方式 | 备注 |
|---|---|---|---|
| 国家统计局 | 原煤产量、工业发电量 | 公开网页 | T1；月度；适合自动保存快照 |
| 国家能源局 | 用电量、火电装机、利用小时 | 公开网页 | T1；月度/年度；适合公告发现 |
| 全国煤炭交易中心 | 国煤直达动力煤价格指数 | 公开页面 | T2；通常是当前值，页面结构可能变化 |
| 巨潮资讯 | 上市公司公告 PDF | 公开公告目录/PDF | T2；适合发电量、上网电量、上网电价、财报 |
| 上海证券交易所 | 定期报告与公告 | 公开页面 | T2；可能出现 403，巨潮资讯可作替代 |
| CCTD | 秦皇岛 5500/5000/4500K 历史价格 | 合法 CSV/API | 需注册或授权；适合补历史序列 |

不建议绕过登录、验证码、付费墙或访问限制。免费方案使用公开指数建立当前序列，历史价格通过合法导出的 CSV 补齐；授权 API 只在确实需要无人值守历史更新时再购买。
