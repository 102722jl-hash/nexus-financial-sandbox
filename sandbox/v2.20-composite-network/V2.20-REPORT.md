# NEXUS V2.20.0 复合网络编译验收

## 版本身份

- 当前版本：`V2.20.0-composite`
- 冻结父版本：`V2.19.13-frozen`
- 默认端口：4186
- 版本文件：`VERSION.json`
- 复合门禁契约：`data-graph-scenario-readiness-1.0.0`

## 新增能力

- 数据、图结构、情景传播分别输出独立状态。
- 画像结果提供字段数、映射数、确认数、AI候选数、未识别数和表角色状态。
- 网络编译检查重复节点、重复关系、关系端点、非法层级和阻断问题。
- 未知公式、孤立节点、单位族冲突和传播循环进入可见告警。
- 自动计算可调节点、候选/正式传播边、末端结果节点和传播覆盖率。
- 只有存在可调节点到结果节点的完整路径时才进入 `SCENARIO_READY`。
- 页面显示 `DATA_READY / GRAPH_READY / SCENARIO_READY`，不再用一个“同步成功”混合所有状态。
- 保留 V2.19.13 的通用公式、候选传播、动态线条和变量调整能力。
- 新增行业无关的 `nexus-crawler-batch-1.0.0`，统一网络身份、批次、来源、快照、证据、实体、指标、观测、层级、公式和关系。
- 新网络总标题来自显式 `network_name`；节点分类来自 `default_layer_code`；不再由网页根据字段名临时猜测。
- 入库前自动检查引用完整性、时间截止、单位一致性、SHA-256、主键冲突、公式注册和可调节点到结果节点的路径。
- 局部坏数据进入隔离区，结构性错误阻断网络编译；`AI_APPROVED` 默认进入候选传播但维持 `ABSTAIN`。
- 新增 PostgreSQL 增量幂等入库器，不再使用整表清空重写。
- 新增契约到浏览器网络的确定性编译器，自动生成总标题、节点层级、基准值、可调状态和传播关系。
- 新能源汽车现有数据库已转换为标准批次并生成 77 个节点、66 条关系；127 条观测全部通过契约。
- 新能源汽车渗透率 +20% 的回归试算传播到 15 个节点，产生 17 步计算记录，输出保持 `CANDIDATE_SCENARIO / ABSTAIN`。

## 当前边界

- 自动分类基于显式网络定义、标准字段规则、历史映射缓存和 AI 候选；不能从完全无语义的数字字段可靠推断正式因果。
- 未识别字段默认隔离；不会因局部字段失败而阻断已验证网络路径。
- 循环关系当前允许作为候选图进入，但必须使用影响上限和收敛保护。
- 正式因果关系仍需要证据、参数校准和正式确认；AI候选保持 `ABSTAIN`。
