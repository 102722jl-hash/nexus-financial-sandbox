# V2.20 复合网络编译架构

## 三道门禁

1. `DATA_READY`：来源已画像，关键字段已映射，可安全同步。
2. `GRAPH_READY`：节点有有效层级，关系端点存在，图结构没有阻断问题。
3. `SCENARIO_READY`：至少存在一条从可调节点到下游结果的可计算路径。

## 编译优先级

```text
来源显式定义
→ 历史映射记忆
→ 标准指标目录和确定性规则
→ 行业模板
→ AI_APPROVED 候选
→ 隔离区
```

## 激活原则

- 局部未知字段、未知公式和孤立节点进入隔离区，不阻断其他有效路径。
- 关系端点缺失、重复节点、非法层级等结构错误阻断 `GRAPH_READY`。
- 没有可传播路径时允许查看数据图，但 `SCENARIO_READY=false`。
- `AI_APPROVED` 可以进行候选条件传播，但保持 `AI_ASSUMPTION / ABSTAIN`。
