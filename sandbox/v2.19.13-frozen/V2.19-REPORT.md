- 修复自定义网络仍显示焦煤情景：进入独立网络时使用空白的自定义情景，退出时恢复原行业情景。
- 任意含数值基线的导入指标都可直接调节；没有已确认下游关系时只改变本节点并显示下游 `ABSTAIN`，有关系时按权重、方向和滞后传播。
- 右侧结果滑块绑定当前选中指标，标题改为“所选指标情景变化”，不再显示焦煤价格。
- 新增预编译网络表结构签名，自动识别并确认控制字段、标准财务字段及数值计算指标。
- 节点和连线 JSON 在只读同步阶段完整读取并严格校验，合法结构直接生成 `PRECOMPILED_NETWORK`；真正模糊的文本字段才需人工审核。
- 新增预编译适配器 28 项测试、列式预编译工作表 45 项测试、完整 API 闭环 13 项测试和通用无因果边调节 16 项浏览器测试。

## V2.19.10 宽表语义分流修复

- 后台先执行标准指标、本地中文财务词典和空值画像分流，再把真正未知且有样例的字段提交 AI。
- 本地分流候选进入同一个任务结果，不会在远程批次启动时被清空；前端分别显示本地识别、空值跳过、AI 排队和失败数量。
- 语义请求保持 4 字段/批，并发由 6 降至 3；单批默认 60 秒且允许 20 至 120 秒配置，兼顾慢中转站和服务稳定性。
- AI 输出改用紧凑字段协议和较小输出预算，同时兼容原完整响应格式。
- 真实 `asharecashflow` 画像共 126 列：14 列标准词典直接识别、56 列可获得本地中文财务语义、49 列样例全空；排除重叠后只需向 AI 排队 22 列。
- 新增宽表分流、空值跳过、本地候选保留和前端路由进度测试。

## V2.19.9 生成网络交互修复

- 节点画布显示当前导入值、单位和实体覆盖，不再只有字段名。
- 导入实体抽屉与内置 AI/焦煤公司模型隔离，不再错误显示中国神华。
- 所有已显示指标都补齐到相应实体的谱系边；默认聚焦所选节点，避免完整连线形成不可读线团。
- 节点密集层自动拉高画布并纵向滚动，13 个以上实体不再重叠。
- 增加“AI生成关系候选 → 勾选确认 → 激活”的审核闭环。
- 已确认情景边支持节点滑杆、方向/权重/滞后确定性传播、动态粒子、方向箭头和逐边计算账。
- 公司适配器未接入时只显示 `SCENARIO_PATH_ONLY`，估值继续 `ABSTAIN`。
- 已生成旧网络加载时按来源字段补充已知中文名和缺失谱系边。
- PostgreSQL/MySQL 画像读取列注释；已核验当前三张 A 股财务表共 422 列、列注释为 0，因此仍需本地词典与 AI 语义层。

## 已实现

- 网络方案支持 UPDATE_EXISTING 与 CREATE_NEW_NETWORK。
- CREATE_NEW_NETWORK 的画布只使用当前导入快照，不继承活动领域节点或边。

- 财务披露关系使用 CONFIRMED_LINEAGE / CONFIRMED_STRUCTURE，不冒充因果传播。

- UPDATE_EXISTING 保留 V2.18 的焦煤—钢铁覆盖模式。

## 自定义数据库表适配器

- PostgreSQL / MySQL 的数据库、Schema、表名和列名支持 Unicode、中文、数字日期前缀及名称内的句点。
- 字段来源以 `database / schema / table / column` 结构化定位保存，不再依赖拆分点号字符串。
- PostgreSQL 查询只使用 `psycopg.sql.Identifier`；MySQL 标识符统一反引号转义并将内嵌反引号双写。
- 映射中的数据库名必须与当前连接一致，跨库误映射直接拒绝。
- 实体、报告期、公告日和版本时间由用户确认的标准指标映射控制；日期门禁统一比较前 8 位日期。
- 表画像按选定表逐张执行，界面显示“已选 N 张表”及当前/完成进度。
- 连接错误与画像错误分开显示；画像失败保持“连接正常 · 画像失败”，并在按钮旁显示失败表和后端原因。
- 导入目标已前移到数据库连接之前：创建新网络、增加当前网络、覆盖当前网络数据分别控制画像目录、实体筛选、领域面板和编译策略。
- 创建新网络不加载焦煤—钢铁专属指标；未知数值列生成来源自定义指标候选，文本型数值通过每表最多 50 行的只读值形态画像识别。
- 表名年份可生成待确认的表级报告期；原表缺少公告日时可使用同步截止日作为快照边界，但标记为不可用于历史回放。
- 包含自定义指标的新画布标记为 SOURCE_DEFINED_NETWORK，六层改用市场与成长、运营与效率、资本与风险、结果与质量等通用语义。
- MySQL 标识符中的百分号会在 PyMySQL 参数展开层安全双写，避免含“净利率(%)”等列名触发格式化错误。
- 创建新网络且来源没有实体键时，提供待确认的 ROW_HASH 自动行标识；画布最多展示 20 个实体，完整同步结果不丢弃。
- 生成网络注册为独立本地资源，显示在右上角“世界网络”选择器中；支持切换、重载和删除，删除网络不删除数据源。
- 生成网络开放实体页、来源指标对比、关系模型页和六层播放；动态线表达数据谱系或会计结构，未确认因果关系时情景数值继续 ABSTAIN。
- 静态领域估值与生成网络面板已隔离；生成网络保持 ABSTAIN / DATA_MISSING，切回 AI 或煤钢后恢复对应公司市值模型。
- 创建新网络时，后端可将字段结构、统计摘要和最多五个有限样例交给已配置的 AI，生成中文指标名、业务定义、类型、单位与六层归属候选；敏感列不提供样例。
- `column_76` 等技术列名禁止批量直接确认；AI候选经用户确认后才进入同步和图编译，节点保留 confidence、reason 与画像证据。
- 缺少实体名称时画布使用“数据记录 01”作为可读标题，稳定行哈希仅作为审计标识。
- AI 任务允许 PARTIAL：成功候选立即保留，逐项显示 TIMEOUT 等失败类型，并只重试未完成字段；语义批次使用至少 90 秒等待。
- 页面刷新通过脱敏工作区接口恢复数据源、已选表、映射、同步摘要、指标值和网络方案；当前自定义网络 ID 写入 URL 并自动重载。
- 密码和 AI Key 不进入刷新状态；未激活工作区仅保证同一后端进程内刷新恢复，已激活网络可以跨后端重启恢复。

## 边界

仅导入公司财务表不能自动证明宏观、供需和产业链因果。若要把独立披露网络升级为可推演的行业世界网络，数据库还需提供行业指标、节点语义、已确认关系、权重、滞后、机制、证据和公司暴露。AI 可以提出候选，但不能直接激活。
